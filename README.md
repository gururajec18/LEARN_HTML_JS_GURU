# HTML & JavaScript Coding Studio

> **Developed by Gururaj Surampalli**

A modern, responsive, all-in-one web application designed for learning, experimenting, and building with **HTML5** and **JavaScript**.

---

## 🌟 Key Features

1. **HTML Basics & Guides**:
   - Document structure & boilerplate (`<!DOCTYPE>`, `<html>`, `<head>`, `<body>`)
   - Headings (`<h1>`–`<h6>`), Paragraphs, typography, and inline tags
   - Links, Images, Audio, and Video media embedding
   - Lists (`<ul>`, `<ol>`, `<li>`) and structured Tables (`<table>`, `<thead>`, `<tbody>`)
   - Interactive Forms (`<input>`, `<textarea>`, `<select>`, `<button>`)
   - Semantic HTML elements (`<header>`, `<nav>`, `<main>`, `<article>`, `<section>`, `<footer>`)

2. **JavaScript Basics & Concepts**:
   - Variables & Primitive Data Types (`let`, `const`, `var`, strings, numbers, booleans, objects)
   - Operators & Control Flow (`===`, `!==`, ternary operator, `if`/`else`)
   - Loops & Iteration (`for`, `while`, `for...of`, `for...in`)
   - Functions & Scope (Arrow functions, function declarations, parameters)
   - Arrays & Objects (`map`, `filter`, `reduce`, object destructuring)
   - DOM Manipulation & Events (`querySelector`, `addEventListener`, `classList`, dynamic nodes)

3. **18+ Rich Practical Examples**:
   - Ready-to-run interactive examples selectable from the sidebar:
     1. *HTML Document & Tags Showcase*
     2. *Interactive Text Styler & Badge Bar*
     3. *Interactive Counter with Step & Limits*
     4. *Live Character & Word Counter*
     5. *Dark & Light Theme Switcher*
     6. *Random Color Generator & Flipper*
     7. *Dynamic Item List (Create & Delete)*
     8. *Interactive Modal & Popup Window*
     9. *Live Digital Clock & Timezone Display*
     10. *Bill & Tip Split Calculator*
     11. *Real-time Search & Filter List*
     12. *Collapsible Accordion & FAQ*
     13. *Precision Stopwatch (Lap & Reset)*
     14. *Interactive Quiz with Instant Feedback*
     15. *Customizable Password Generator*
     16. *HTML5 Canvas Interactive Drawing Pad*
     17. *Async Data Loader & Card Renderer*
     18. *Dynamic CSS Box Styler & Generator*

4. **3 Complete HTML + JavaScript Mini Projects**:
   - 🚀 **Smart TaskMaster**: Interactive task manager with filters (All, Active, Completed), item counters, and deletion.
   - 🧮 **Clean Modern Calculator**: Functional glassmorphic calculator with chained operations and decimal handling.
   - 🍅 **Pomodoro Focus & Study Timer**: 25m focus sprint timer with short/long break toggles and completed sprint tracker.

5. **Developer Code Editor**:
   - Tabbed view: **HTML**, **CSS**, and **JavaScript**
   - Synchronized line numbers and indentation
   - `Tab` key handling (indents 2 spaces without losing focus)
   - Keyboard shortcut: **`Ctrl + Enter`** to quickly execute code
   - Optional **Auto-run** mode with real-time preview updates

6. **Live Program Execution & Built-in Virtual Console**:
   - Sandboxed isolated `<iframe>` execution
   - Captures and colorizes `console.log`, `console.info`, `console.warn`, `console.error`, and runtime errors
   - Live log timestamps and counter badges

7. **Reset, Clear, Copy & Export**:
   - **Reset**: Instantly restores the original template code
   - **Clear**: Clears the editor to code from scratch
   - **Copy**: One-click code copying to clipboard
   - **Export .html**: Download a standalone runnable `.html` bundle file

8. **Modern Responsive Interface**:
   - Dark developer studio aesthetic
   - Mobile navigation drawer
   - Fullscreen preview mode

---

## 🚀 How to Run the App

Simply open `index.html` in any modern web browser (Google Chrome, Microsoft Edge, Firefox, Safari):

```bash
# Double-click index.html or run in PowerShell:
Start-Process index.html
```
